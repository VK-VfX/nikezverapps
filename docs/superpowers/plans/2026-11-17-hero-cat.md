# Hero Cat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When Purrcast, Zamoled and Maps and Cats are all installed, a masked superhero Noto cat appears in all three: weather emotions on every Purrcast widget, a hero-cat wallpaper look in Zamoled, and a walking parade on the Maps and Cats Settings page. Until then a silhouette teaser shows.

**Architecture:** The art is drawn once as SVG and exported to the three apps' formats by one script. Each app asks "are the other two installed?" through the existing package check and switches its own art on or off. Nothing is stored or sent.

**Tech Stack:** SVG plus a small Python export script (Pillow, `cairosvg` or `rsvg-convert`); Purrcast plain Java; Zamoled Kotlin; Maps and Cats web with CSS animation.

**Spec:** `docs/superpowers/specs/2026-11-17-trio-streaks-and-hero-cat-design.md` (sections 3 to 5). **Depends on:** `2026-11-17-trio-streaks-shield.md` for `Trio.allInstalled` in each app (Purrcast and Zamoled) and the bridge check in Maps and Cats.

## Global Constraints
- Nine emotions: `smile`, `grin`, `smirk`, `confident`, `angry`, `shocked`, `sad`, `scared`, `loaf`, plus one `locked` silhouette. File names: `hero-<design>.svg`.
- Only Noto cats: every design is the Noto cat head from `mapsandcats/assets/cats/` with the same red domino mask, cape and gold-star collar; only the face changes (build.py is the source). Keep the `svgmoji` licence notice next to the art.
- Pitch black: the art has a transparent background; nothing is drawn behind it.
- Animation uses only `transform` and `opacity`, and stops completely under the phone's "remove animations" setting.
- Emotion choice in Purrcast follows the weather icon (proposed mapping: SUN/SUNRISE -> smile, SHADES -> confident, PARTLY/CLOUD -> smirk, RAIN/DRIZZLE/UMBRELLA -> sad, STORM -> angry, WIND -> shocked, COLD/SNOW -> scared, SWEAT -> grin, MOON/SLEEPY -> loaf, others -> smile); a "Show hero cat" switch (default on) turns it off.
- Plain Java in Purrcast (no lambdas, no AndroidX). Local commits only; **do not push, build releases or bump versions** until the owner says so.

## Review Focus
- Only two of three apps installed: the hero art and the shield stay off, the teaser shows, nothing crashes.
- An app uninstalled while widgets are on the home screen: the next refresh falls back to the normal cats.
- "Show hero cat" switched off: widgets, streak card and notifications use the normal cats again.
- Notification text and any text-only place: still use the plain cat emoji (the hero art is image-only).
- Reduced motion on: the Maps and Cats parade is a still row; Zamoled wallpapers stay pitch black (corners exactly `#000000`).
