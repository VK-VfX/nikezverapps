# UX profile (Purrcast, Zamoled, Maps and Cats)

Applies to all three apps in this monorepo.

## Aesthetic reference
**Raycast**: black, high contrast, compact, utility-first, mono details.
Shared look: teal accent `#3DF5D0`, black background, ~24dp cards, condensed bold headings, mono captions, same profile picture, same About card.

## Banned anti-aesthetics
- Glassmorphism / `backdrop-filter` blur without a high-contrast edge
- Pastel pill badges for ordinary metadata
- Decorative gradients and neon glow borders (teal is the single accent)
- Rainbow gradients on buttons
- Cartoon empty-state illustrations
- Nested scrollbars; icon bloat inside inputs
- Any emoji other than the cats below

## Accessibility target
**WCAG 2.1 AAA**: text contrast above 7:1 (no dim grey captions, mono captions included), 48x48 px touch targets, prominent focus outlines.

## Brand tone
**Warm & Humancentric**: clear, friendly, a little witty, never cold. Cheerful copy, Malaysian-friendly where it fits.

## Icons and emoji
- Icon library: **none**; project SVG / inline vectors only. One hand-made set, one stroke weight, no mixing. No packages installed.
- Emoji: **only Google Noto cat emoji**, plus the owner's own customised variants (sunglasses, umbrella and similar accessories). No other emoji or mascot style. No emoji as UI icons except these cats.
