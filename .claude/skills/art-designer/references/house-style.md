# House style (from `.ux-profile.md`, root `CLAUDE.md`, `docs/DESIGN.md`)

- Aesthetic reference: Raycast. Black, high contrast, compact, utility-first, mono details.
- Palette: pure black `#000000` background, single accent teal `#3DF5D0`. No decorative gradients, no neon glow borders, no rainbow buttons, no glassmorphism without a high-contrast edge, no pastel pill badges for plain metadata.
- Shape and type: about 24dp cards, condensed bold headings, mono captions (captions still need >7:1 contrast).
- Shared pieces: same profile picture, same About card in all three apps.
- Accessibility target: WCAG 2.1 AAA, 48x48 targets, prominent focus outlines.
- Tone: warm and humancentric, clear, friendly, a little witty, never cold.
- Icons: no icon library; hand-made inline vectors, one stroke weight.
- Emoji: Google Noto cats only, plus the owner's customised accessories (sunglasses, umbrella and similar). Hero cats are in `trio-art/hero-cats` (five mask looks, every emotion `hero-<emotion>-<0..4>`, plus a locked silhouette); rules in `docs/HERO-CAT-RULES.md`, artwork notes in `docs/ARTWORK.md`.
- Hero cat moods: angry and sad appear only when the weather is bad; decoration uses the calm set.
- Always read `docs/DESIGN.md` and `docs/ARTWORK.md` before new art; check them for the current rules since they change.
